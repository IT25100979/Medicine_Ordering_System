🩺 MediLink — Order Processing Test UI

Function 03: Real-Time Order Processing & State Workflow Tracking — quick manual test panel for your local Spring Boot backend.

➕ Create Order POST /api/orders

🔍 Get Order GET /api/orders/{id}

🔄 Update Status PUT /api/orders/{id}/status

📋 Orders by Customer GET /api/orders/customer/{id}

Runs entirely in your browser — talks directly to your local Spring Boot app.
Make sure your backend is running (MedilinkApplication.java) and @CrossOrigin(origins = "*") is set on your controllers.
